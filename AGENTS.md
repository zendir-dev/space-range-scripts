# AGENTS.md — space-range-scripts

## Zendir team standards

If **zendir-skills** is installed, follow its shared standards
(https://github.com/zendir-dev/zendir-skills). Treat it as installed when the `ZENDIR_SKILLS`
environment variable is set, or when the sibling folder `../zendir-skills` exists.

When it is installed, before writing or reviewing code:

1. Read `zendir-skills/products/space-range-scripts/README.md` for this repo's context and the standards that apply.
2. Read `zendir-skills/standards/general/README.md` and `zendir-skills/standards/languages/<language>/README.md`
   for each language you touch, and open linked topic files as needed.

When it is installed, precedence is: rules in this file > `products/space-range-scripts` > language standards > general standards.
Only put rules in this file that are specific to this repo and haven't been moved to zendir-skills yet.

When it is not installed, follow the conventions already used in this repository.
